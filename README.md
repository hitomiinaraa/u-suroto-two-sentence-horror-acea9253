An entry for the [Two-Sentence Horror](https://make.fun/bounty/u-suroto-two-sentence-horror-acea9253) bounty on make.fun: one original horror story told in exactly two sentences.

> The lighthouse keeper's log ended mid-sentence on the night the light went out. I finished reading it at dawn, and the handwriting for the last page was mine.

## Run it

```sh
node main.ts
```

This writes the story to `/output/entry.txt` and prints it.
